About this project

Mutagen is a student coding and biology project by Hudson S. Classmates suggest small ideas, and approved ones are added to this page. The dish is a simple computer model of how bacteria grow, divide and mutate. The background changes each day: a program solving a Minesweeper board using only the clues a player can see, a reaction-diffusion simulation (the math behind coral and animal spots), a fluid simulation, drifting Perlin noise drawn as a contour map, a slime mold growing veins, Conway's Game of Life, spiraling cellular automata, ripples, crystal growth, or Langton's ants. The screensaver lets you pick any of them or cycle through them all.

How requests are handled

  • Only people on the class list can have a request added, so nothing is anonymous.
  • An AI screens every request first and removes anything unsafe, unkind or off limits.
  • Only a first name and last initial are shown.
  • Widgets run only on this page and are blocked from connecting to anything outside it.

Rules

No chat or messaging, nothing that helps with cheating, no personal information, and keep it school-appropriate. Requests that break these are removed. If you see a problem, tell Hudson S and it will be taken down.
